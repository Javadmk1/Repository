# AutoSubtitle

An Android app project for creating Persian and English subtitles.

## Planned features

- Select a local video or audio file on Android
- Create and edit subtitle entries
- Export UTF-8 SRT subtitle files
- Later: automatic Persian/English speech recognition and timestamping
- Later: export a subtitled MP4

## Current status

Project initialization. Automatic speech recognition and MP4 subtitle rendering are not implemented yet.

## Development plan

1. Build the Android starter app and subtitle editor.
2. Add SRT import/export and test on Android.
3. Integrate speech recognition for Persian and English.
4. Add subtitle rendering/export to MP4.
